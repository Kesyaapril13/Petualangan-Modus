# Petualangan Modus 🎮

Aplikasi game pembelajaran matematika materi **Statistika: Modus**, dibuat untuk tugas Alpro.

## Fitur
- **Halaman awal**: isi nama pemain dan lihat skor terbaik
- **Materi**: pengertian modus, langkah mencari modus, data dengan dua modus, tabel frekuensi, soal cerita
- **Latihan Soal**: 5 soal modus, jawab satu per satu, lengkap dengan pembahasan per tahap
- **Game Kuis**: soal diacak, 3 nyawa, skor, bonus jawaban beruntun
- **Hasil**: skor, bintang, dan daftar soal yang perlu dipelajari lagi

## Cara menjalankan
Buka file `index.html` di browser, atau gunakan Live Server di VS Code.

## Teknologi
HTML, CSS, dan JavaScript
